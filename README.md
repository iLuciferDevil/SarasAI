# AI Engineer Program Landing Page
## Saras AI Institute - Working Prototype

### What's Included

This is a fully functional landing page with a complete intake/application form for the AI Engineer program.

### Features

**Landing Page Sections:**
- Hero section with trust signals (state-licensed, industry leaders, etc.)
- Career outcomes (AI Engineer, AI Product Manager, AI Lead)
- Real projects timeline (12-month breakdown)
- Learning model features
- Student testimonials with outcomes
- Transparent pricing ($6,000)
- Programs pathway (Powers of AI → Associate → Bachelor → Master)
- Sticky CTA button (appears on scroll)

**5-Step Intake Form:**
1. **Profile** (Name, Email, Country, Phone)
2. **Background** (Role, Years coding, Language, Python experience)
3. **Portfolio** (Resume link, GitHub, Why AI Engineering statement)
4. **Program Details** (Start date, Hours/week, Financial aid needs)
5. **Confirmation** (Review info, agree to updates, submit)

### Form Features
- Progress bar shows completion (20% per step)
- Form validation on required fields
- Back/Next navigation
- Mobile responsive
- Smooth animations
- Professional styling
- Fully functional submission

### How to Use

**Option 1: Open Locally**
1. Download the index.html file
2. Open in any web browser (Chrome, Safari, Firefox, etc.)
3. Test all functionality: scroll, click buttons, fill form

**Option 2: Deploy Online (Free)**

**Deploy to Vercel (recommended, instant & free):**
1. Go to https://vercel.com
2. Sign up with GitHub
3. Click "New Project" → "Import Git Repository"
4. Upload this HTML file
5. Deploy (instant)
6. Share the link with Saras

**Deploy to Netlify (also free):**
1. Go to https://netlify.com
2. Sign up
3. Drag & drop the index.html file
4. Instant live link

**Deploy to GitHub Pages (free):**
1. Create a GitHub repo
2. Upload index.html as the main file
3. Enable GitHub Pages in Settings
4. Live in seconds

### What Works in the Form

- Fill out all 5 steps
- Progress bar updates as you move through steps
- Back button to review previous answers
- Form validation (won't let you skip required fields)
- Final confirmation shows your entered data
- Click "Submit Application" → success message
